## 第 32 题 · 最长有效括号

字符串 `s` 只含左右圆括号。找出其中最长的一段连续子串，使这一段里的括号都能按顺序正确配对。返回它的字符数。 [力扣原题全文](https://leetcode.cn/problems/longest-valid-parentheses/description/)

**数据范围**　字符串长度为 0–30000。

**题目样例**　`"(()"` → `2`，其中最长的一段是 `"()"`。`")()())"` → `4`。空串 → `0`。

## 解题思路

当时问的是 `"()(()"`：读到尾部才知道少一个右括号，前面的长度该怎么算？实际上下标 0–1 和 3–4 各有一段 `"()"`，中间下标 2 的左括号把它们隔开了。最长是 2。只数左右括号各有几个，会丢掉这条分界线。

栈里保存尚未配对的左括号下标，底部放最近一次失配的右括号下标，初始为 −1。匹配成功后，新的栈顶正好是当前合法后缀之前的位置。上例读到最后一个右括号时，弹出 3，露出 2，长度就是 4 − 2。

```python
def longest_valid(s):
    stack = [-1]
    best = 0
    for i, ch in enumerate(s):
        if ch == '(':
            stack.append(i)
        else:
            stack.pop()
            if stack:
                best = max(best, i - stack[-1])
            else:
                stack.append(i)
    return best
```


每个下标最多入栈和出栈各一次，时间为 O(n)。全是左括号时栈最长，额外空间为 O(n)。
