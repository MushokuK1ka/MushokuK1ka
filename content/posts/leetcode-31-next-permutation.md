## 第 31 题 · 下一个排列

给定整数数组 `nums`，把它改成字典序中紧接在当前排列之后的那个排列。如果当前已经是最大的排列，就回到最小的排列。直接修改输入数组，只允许使用 O(1) 额外空间。 [力扣原题全文](https://leetcode.cn/problems/next-permutation/description/)

**数据范围**　数组含 1–100 个元素，每个元素在 0–100 之间，可以重复。

**题目样例**　`[1, 2, 3]` → `[1, 3, 2]`。`[3, 2, 1]` → `[1, 2, 3]`。`[1, 1, 5]` → `[1, 5, 1]`。

## 解题思路

最初想到从右往左找一个可以变大的位置，交换，再把后面排序。用 `[2, 1, 5, 4, 3]` 手推才看清交换对象：能改的是 1，和相邻的 5 交换会一下跳过许多排列。右边比 1 大的数里，最小的是 3。换完得到 `[2, 3, 5, 4, 1]`，把后缀翻转，才是讨论中算出的 `[2, 3, 1, 4, 5]`。

从右边找到第一个 `a[i] < a[i+1]` 时，右侧已经按非递增顺序排列。从末尾遇到的第一个比 `a[i]` 大的数就是要换的数。换后后缀仍然非递增，所以原地翻转即可。若一路找不到这个位置，整个数组已经是最后一个排列，直接翻转回第一个。

```python
def next_permutation(a):
    i = len(a) - 2
    while i >= 0 and a[i] >= a[i + 1]:
        i -= 1
    if i >= 0:
        j = len(a) - 1
        while a[j] <= a[i]:
            j -= 1
        a[i], a[j] = a[j], a[i]
    left, right = i + 1, len(a) - 1
    while left < right:
        a[left], a[right] = a[right], a[left]
        left += 1
        right -= 1
```


找交换点和翻转后缀都只需线性扫描，最坏时间 O(n)。交换始终在原数组里完成。
