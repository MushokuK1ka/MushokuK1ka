leetcode40:组合总和 II

题面与示例（2 组）

给定一组正整数 candidates 和目标整数 target。从数组中挑选若干个位置，使这些位置上的数字相加恰好等于目标，列出所有不同的组合。

每个位置在同一组合中最多取一次。输入可以含有相同的值，如果有两个 1，就可以把这两个 1 一起选入。按数字比较结果，相同的组合只保留一份，不能靠更换位置或调换顺序重复计入。

数据范围　候选数共 1–100 个，数值为 1–50，目标为 1–30。

示例 1

输入
candidates = [10, 1, 2, 7, 6, 1, 5], target = 8
输出
[[1, 1, 6], [1, 2, 5], [1, 7], [2, 6]]

输入里有两个独立的 1，所以 [1, 1, 6] 可以成立。用不同位置的 1 和 7 配对，得到的 [1, 7] 只收录一次。

示例 2

输入
candidates = [2, 5, 2, 1, 2], target = 5
输出
[[1, 2, 2], [5]]

可从三个 2 中挑两个配上 1，或者只选 5。所有挑法只对应这两种值组合。

题目来源：力扣 40 · 组合总和 II

解题思路

第 40 题的每个位置只能用一次。我把递归起点改成 i + 1，打算收集完结果再去重，却超了内存。这里还缺一个条件。给两个值相同的 1 标上 1a、1b：在同一层先选 1a 或先选 1b，会产生重复的值组合。已经选完 1a 后，下一层再选 1b，却是得到 [1, 1, 6] 的必要步骤。所以跳过重复数字的条件必须包含 i > start。

def combinations(candidates, target):
    values = sorted(candidates, reverse=True)
    result, path = [], []

    def visit(start, remaining):
        if remaining == 0:
            result.append(path.copy())
            return
        for i in range(start, len(values)):
            value = values[i]
            if value > remaining:
                continue
            if i > start and value == values[i - 1]:
                continue
            path.append(value)
            visit(i + 1, remaining - value)
            path.pop()

    visit(0, target)
    return result

候选数按降序排列。如果当前值大于剩余的和，后面还可能有较小的值可选，所以用 continue。找到答案时保存 path.copy()，让后面撤销选择的 pop() 只影响当前路径。
