leetcode38:外观数列

题面与示例（2 组）

外观数列的每一项都是字符串。第一项是 "1"，以后每一项取上一项的行程长度编码。给定正整数 n，返回第 n 项。

编码时从左向右，把连续相同的数字分成尽可能长的一段，再依次写下各段的长度和该段的数字。例如，3322251 分为 33 | 222 | 5 | 1，分别写成 23 | 32 | 15 | 11，拼起来就是 23321511。同一个数字如果隔开出现，需要分段计数。

进阶要求：尝试用迭代生成各项。

数据范围　1 ≤ n ≤ 30。

示例 1

输入
n = 4
输出
"1211"

依次得到 "1"、"11"、"21"、"1211"。第三项 "21" 有一个 2，接着有一个 1。

示例 2

输入
n = 1
输出
"1"

第一项由定义直接给出。

题目来源：力扣 38 · 外观数列

解题思路

这题的想法可以直接写成函数：给定上一项，把连续相同字符的长度和字符依次写入列表，再拼成下一项。1211 可以分为 1 | 2 | 11，读成“一个 1、一个 2、两个 1”，就得到 111221。相隔的两个 1 属于不同段，不能把整串交给词频表。

def count_and_say(n):
    term = '1'
    for _ in range(1, n):
        parts = []
        start = 0
        while start < len(term):
            end = start + 1
            while end < len(term) and term[end] == term[start]:
                end += 1
            parts.extend([str(end - start), term[start]])
            start = end
        term = ''.join(parts)
    return term

例如算到第 4 项时，依次得到 1 → 11 → 21 → 1211。每一步只读上一项一次，用列表收集片段，最后一次拼接。总耗时取决于这 n 项的字符总数。
