编码与格式

转换文本、校验数据格式。

  • URL 编解码

    转换网址参数中的百分号编码，页面可切换到解码。

    urlencoder.org

  • JSONLint

    检查 JSON 语法并整理缩进。

    jsonlint.com

  • Base64 编解码

    将文本转换为 Base64，或切换到解码页面还原文本。

    base64encode.org
#

密码学

计算文本哈希和文件校验值。

  • CyberChef

    执行哈希、Base64 转换及其他数据处理操作。

    gchq.github.io

  • SHA-256 文本哈希

    输入文本，计算对应的 SHA-256 摘要。

    emn178.github.io

  • SHA-256 文件校验

    选择本地文件计算校验值，便于核对下载文件。

    emn178.github.io

开源与镜像

查找项目源码、模型数据和容器镜像。

  • GitHub

    查找开源项目、源码和发布版本。

    github.com

  • Hugging Face

    浏览机器学习模型、数据集与在线演示。

    huggingface.co

  • HF-Mirror

    Hugging Face 模型和数据集的第三方镜像。

    hf-mirror.com

  • Docker Hub

    查找容器镜像及其版本标签。

    hub.docker.com

建站工具

注册域名、查询 DNS 记录和检测网站连通性。

  • Google Admin Toolbox · Dig

    输入域名并选择记录类型，查询 DNS 解析结果。

    toolbox.googleapps.com

  • DNSHE

    查看域名注册和 DNS 解析服务。

    dnshe.com

  • 站长工具 · 多地 Ping

    从多个探测点查看目标的延迟和连通性。

    ping.chinaz.com

开发辅助

调试正则、比较文本和转换时间戳。

  • regex101 · 正则测试

    输入表达式和样本文本，查看匹配结果及分组。

    regex101.com

  • Diffchecker · 文本对比

    并排比较两段文本，定位增加、删除和修改的行。

    diffchecker.com

  • Epoch Converter · 时间戳转换

    在 Unix 时间戳和可读日期之间转换。

    epochconverter.com
